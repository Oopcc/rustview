# RustView

Маленький быстрый кроссплатформенный просмотрщик картинок на Rust.
Открывает **GIF** и **WebP** (в том числе анимированные), PNG, JPEG, BMP, ICO, TIFF, TGA, QOI, PNM.

[English version](README.md)

## Возможности

- Двойной клик по картинке в проводнике: открывается RustView, и можно листать остальные картинки из этой же папки
- Стрелки для перехода между файлами (естественная сортировка: `img2` раньше `img10`)
- Зум колёсиком (к курсору), перемещение мышью, двойной клик: по размеру окна / 100%
- GIF / WebP анимации: пауза, покадровая перемотка
- Поворот, полный экран, перетаскивание файла в окно
- Формат определяется по содержимому, так что WebP с расширением `.jpg` тоже откроется
- Один небольшой файл, без зависимостей

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `←` / `→`, `PgUp` / `PgDn` | предыдущая / следующая картинка |
| `Home` / `End` | первая / последняя |
| Колесо, `↑` / `↓`, `+` / `-` | зум |
| Перетаскивание, двойной клик | сдвиг, 100% / по размеру окна |
| `0` / `1` | по размеру окна / реальный размер |
| `R` / `Shift+R` | поворот по / против часовой |
| `Space` | пауза / play анимации (у статичной: следующая) |
| `,` / `.` | предыдущий / следующий кадр |
| `F`, `F11`, `Enter` | полный экран |
| `I` | показать / скрыть инфо-строку |
| `H`, `F1` | справка |
| `Esc` | выйти из полного экрана / закрыть |

## Установка (Windows)

Скачай `RustView-Setup-x.y.z.exe` из [Releases](../../releases) и запусти.
Установщик регистрирует RustView для всех форматов и ставит иконку приложения на связанные файлы.

> Windows 10/11 не даёт установщикам тихо менять приложения по умолчанию.
> После установки либо отметь последнюю галочку в установщике (откроются *Параметры > Приложения по умолчанию*),
> либо ПКМ по картинке > *Открыть с помощью* > *Выбрать другое приложение* > RustView > *Всегда*.
> Это нужно сделать один раз для каждого формата (`.gif`, `.webp` и т.д.).

К каждому релизу также прикладывается портативный `rustview.exe` (без установки).

## Сборка из исходников

Код полностью кроссплатформенный (Windows, Linux, macOS, ChromeOS через Linux-контейнер). Нужен [Rust](https://rustup.rs) (stable, 1.81+).

```bash
git clone https://github.com/<ты>/rustview
cd rustview
cargo run --release -- путь/к/картинке.webp
cargo build --release          # бинарник: target/release/rustview(.exe)
```

По платформам:

- **Windows**: `cargo build --release`, иконка вшивается автоматически. Для установщика поставь [Inno Setup 6](https://jrsoftware.org/isinfo.php) и выполни
  `"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\rustview.iss` -> `dist\RustView-Setup-<версия>.exe`.
- **Linux**: нужен OpenGL (Mesa). Для интеграции: скопируй `packaging/rustview.desktop` в `~/.local/share/applications/`, а `assets/icon.png` в `~/.local/share/icons/hicolor/512x512/apps/rustview.png`.
- **ChromeOS**: включи *Среду разработки Linux* и повтори шаги для Linux в её терминале.
- **macOS**: `cargo build --release`; для ассоциаций в Finder упакуй в `.app` через [cargo-bundle](https://github.com/burtonageo/cargo-bundle).
